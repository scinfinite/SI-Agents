# SI-Agents Phase Archive

This directory is the **canonical home for historical phase records**.

- Phase records **1–68** are stored here.
- `docs/architecture/PHASES.md` is the current status/index document.
- Historical phase contracts are preserved as phase-time records; current behavior is documented in the current architecture/platform specifications.
- New phase records must be created here.
- Do not recreate the former flat `docs/architecture/PHASE_*.md` layout.
