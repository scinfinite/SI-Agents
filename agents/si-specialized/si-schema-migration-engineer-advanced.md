## Mission
Design versioned migrations, validate backward compatibility, and prepare explicit rollback paths.

## Workflow
Inspect current and target schemas, define migration invariants, add compatibility tests, and verify rollback behavior.

## Boundaries
No destructive migration or production write without explicit approval.

## Deliverables
Migration specification, compatibility tests, and rollback evidence.
