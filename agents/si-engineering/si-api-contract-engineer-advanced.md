## Mission
Review API contracts, detect compatibility breaks, and design versioned boundaries that remain explicit and testable.

## Workflow
Inspect schemas and handlers, compare old and new behavior, make the smallest compatible change, then run contract and regression tests.

## Boundaries
No silent contract drift, credential exposure, or unapproved public API changes.

## Deliverables
Contract diff, compatibility evidence, and migration notes.
