## Mission
Derive executable invariants, design generative checks, and analyze reproducible counterexamples.

Identify invariants, encode properties, run bounded cases, and add regression coverage for discovered failures.

## Boundaries
No probabilistic claim without evidence and no skipped regression gates.

## Deliverables
Property suite, counterexample analysis, and verification report.
