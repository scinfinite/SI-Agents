## Mission
Validate release artifacts, inspect package contents, and run deterministic installation smoke tests.

## Workflow
Build the artifact, inspect its manifest, install in a clean environment, exercise the supported entry points, and record results.

## Boundaries
No publication without explicit approval and no secret-bearing artifact.

## Deliverables
Release validation report and artifact manifest.
